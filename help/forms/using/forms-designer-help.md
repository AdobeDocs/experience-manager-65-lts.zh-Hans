# Forms Designer帮助 {#form-designer-help}

AEM Forms Designer是一个桌面应用程序，用于在Adobe Experience Manager Forms中创作和管理PDF以及基于XFA的自适应表单。 使用以下资源开始使用、探索示例，并参考Designer对此6.5 LTS版本的脚本功能。

* [使用Designer](https://www.adobe.com/go/learn_aemforms_designer_65_lts) - Designer工作区和核心创作概念的概述。
* [Designer快速入门教程](https://www.adobe.com/go/learn_aemforms_designer_quick_start_65_lts) — 有关Designer入门的分步教程。
* [Designer示例](https://www.adobe.com/go/learn_aemforms_designer_samples_65_lts) — 可在Designer中打开和调整的可下载示例表单。
* [Designer脚本基础知识](https://www.adobe.com/go/learn_aemforms_scriptingBasics_65_lts) - Designer表单中的脚本编写简介。
* [Designer脚本引用](https://www.adobe.com/go/learn_aemforms_scriptingReference_65_lts) - Designer中脚本对象和方法的完整引用。
* [Designer FormCalc引用](https://www.adobe.com/go/learn_aemforms_formCalc_65_lts) - Designer内置计算语言FormCalc的完整引用。
